# Изменения

## 1.0.0 — 2026-11-08

- Первый релиз интеграции Bulk Epin Reseller API для FunPay Cardinal.
- Telegram-меню `/bulk`, пошаговая привязка лотов и расширенная JSON-настройка.
- Восемь видов товаров, запрос и подтверждение данных покупателя.
- Предварительный расчёт в USD, порог стоимости и минимальный остаток.
- Тестовый режим без закупки, аварийная остановка `/bulk_off`.
- Дисковый журнал, идемпотентность покупок, восстановление с тем же запросом.
- Выдача после `completed`, ручная сверка неоднозначных отправок, проверка повторяющихся кодов.
- Загрузка новых лотов без перезапуска и проверка конфликта со штатной выдачей.
